# Instructor's Choice Math

A free arithmetic facts practice app (addition, subtraction, multiplication, division, operands 0 to 12).
It runs in any modern browser, can be installed to a phone or computer home screen, and works offline.
Each Student's progress is stored only in the browser on their own device. Nothing is sent anywhere.

Files: `index.html` (the whole app), `manifest.webmanifest` and `sw.js` (install and offline support), two icons.
